## 3. 最终人工演示顺序

开始前执行 `Reset demo`，浏览器宽度建议 1440px。下列项目由候选人在最终提交前逐项确认：

- [ ] 首页默认显示英文；右上角可切换中文，再切回英文，当前 Campaign 和流程状态不丢失。
- [ ] 在 Inbox 打开 `Cycling Camera Launch`，看到的是 Agent 工作待办而不是功能 Tab 导航。
- [ ] 点击 `Analyze 3 materials`，Agent 先给计划；点击 `Start run` 后能看到理解、工具步骤和结果过渡，不是立即闪现最终卡片。
- [ ] 处理上线时间冲突，选择 `8 weeks · Excel`。
- [ ] 处理相邻运动范围，选择 `Pending; excluded from current plan`。
- [ ] 打开 `Brief v1`，确认预算 `$180,000`、有效播放 `2.6M`、CPM `≤ $70`、US/UK、Road/MTB/Urban 和头戴摄像头证据要求。
- [ ] 点击 `Build mix options`，比较 Credibility First 与 Reach Efficiency。
- [ ] 点击 `Test failure`，确认长视频或场景缺口出现，Matrix 无法锁定；点击 `Restore` 后约束恢复。
- [ ] 锁定 Matrix，生成 6 个可追溯到 Matrix Cell 的 Search Package。
- [ ] 点击 `Build calibration batch`，进入 10 人校准。
- [ ] 检查 Torque Atlas 因只有摩托车证据而 Disqualified；检查缺失证据者进入 Needs Review。
- [ ] 对候选提问时，看到“理解 → 工具 → 回答”的阶段、打字机结果和折叠轨迹。
- [ ] Accept 至少 2 名 Qualified，审阅至少 1 个失败样本，并应用一次偏好或显式选择无需调整。
- [ ] 点击 `Approve & expand`，生成 30 名客户候选和 10 名内部 Backup。
- [ ] 执行 `Validate slate`，打开 Client Preview，确认看不到内部备注、历史价格、评分明细、Gmail Thread ID 和 Backup 策略。
- [ ] 发布 Round 1，应用预置客户反馈。
- [ ] 打开 Gap Artifact，确认缺口定位到 UK Urban；先 Promote Backup，再创建只影响 UK Urban 的 Replenishment Package。
- [ ] 确认 Brief 和 Locked Mix 未被反馈改写或标记失效。
- [ ] 打开 Runs，确认目标、步骤、时间、Artifact、失败信息和恢复轨迹可追踪。
- [ ] 关闭/打开 Inspector 不改变聊天位置；`Open comparison` / `查看结果` 能定位到对应 Artifact。
- [ ] 浏览器 Console 无运行时错误，关键按钮没有不可点击或被遮挡的情况。

人工验收如发现问题，应记录复现步骤、当前 Run 阶段和 Artifact 类型；修复后从 Reset 重新执行受影响路径。

## 5. 剩余风险

1. 当前没有 Playwright 浏览器 E2E；领域、状态和组件测试已覆盖主路径，但最终视觉和浏览器事件仍依赖人工验收。
2. Agent 是有限意图的确定性 Demo，不等同于在线通用 LLM；README 和界面必须持续保持这一表述。
3. 原始材料解析和候选搜索使用固定 Fixture，不能据此声称已解决真实数据接入、反爬、数据许可或实时性。
4. Replan Matrix 与 Revise Brief 是设计完整但工程实现较浅的分支，答辩时应按此口径说明。
5. `localStorage` 只适合单用户 Demo；生产环境需要服务端版本、权限、审计和观测。
