# 中英切换验收流程

1. 清除 `creator-mix-planner:locale:v1` 后打开网站，确认导航、Inbox 与 Agent 欢迎语默认为英文。
2. 进入 Cycling Camera Launch 项目，点击 `Analyze 3 materials`，确认 Thinking / Action / Answer 阶段和工具步骤为英文。
3. 点击左侧 `中文`，确认当前页面、既有 Agent 系统消息、下一步建议、右侧 Inspector 与状态标签立即切换为中文，Run 进度不变。
4. 输入一条中文用户消息，再切回 `EN`，确认用户消息保持原文；Creator 名称、handle、ID、URL、YouTube/TikTok/Instagram 保持不变。
5. 依次检查 Brief、Matrix、搜索任务包、Candidate Calibration、Client Review 和 Gap Inspector 的标题、按钮、状态与提示。
6. 刷新页面，确认保留上次语言选择。
7. 点击 Reset demo，确认业务数据重置，但语言选择不变。
8. 切回英文，确认界面即时恢复英文且不会重跑 Agent、关闭 Inspector 或改变当前路由。
